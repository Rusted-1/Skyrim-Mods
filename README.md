# Skyrim Mods

My Skyrim Special Edition mods and patches. Each mod lives in its own folder.

| Mod | Folder | Status |
|---|---|---|
| Music Mods Combined | [`Music_Mods_Combined/`](Music_Mods_Combined/) | FOMOD 0.1.0: merges 8 music mods' track lists with vanilla; verified at file level. In-game test pending |

Each mod folder has its own README. Rules for adding or updating a mod are in
[`CLAUDE.md`](CLAUDE.md). This repo holds only my own work. Other authors' mods and
assets (plugins, music, meshes, textures) are not included.
