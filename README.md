# Skyrim Mods

My Skyrim Special Edition mods and patches. Each mod lives in its own folder.

| Mod | Folder | Status |
|---|---|---|
| Music Mods Combined | [`Music_Mods_Combined/`](Music_Mods_Combined/) | FOMOD 0.6.0: merges 9 music mods with vanilla/LORKHAN, weights them by place and time of day, short pauses; verified at file level. In-game test pending |
| Forgotten City – Delayed Start | [`Forgotten_City_Delayed_Start/`](Forgotten_City_Delayed_Start/) | 1.0.0: light plugin that holds The Forgotten City's courier letter until level 25 (adjustable global); verified at file level. In-game test pending |

Each mod folder has its own README. Rules for adding or updating a mod are in
[`CLAUDE.md`](CLAUDE.md). This repo holds only my own work. Other authors' mods and
assets (plugins, music, meshes, textures) are not included.
